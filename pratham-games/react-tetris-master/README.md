## PHub Tetris

A polished, responsive Tetris built with React, Redux and Immutable.js.

Features
- Smooth controls on desktop and mobile
- Persistent game state (resume after refresh)
- Sound effects via Web Audio API
- Level, lines, next piece and score tracking

Getting Started
- Install: `npm install`
- Run dev server: `npm start` (opens http://127.0.0.1:8080)
- Build: `npm run build` (outputs to `docs/`)

Controls
- Desktop: Arrow keys to move/rotate, Space to hard drop
- Mobile: On-screen controls

  The Problem                                                                   
                                                                                
  In                                                                            
  /Users/prathamranjan/PHub/frontend/nextjs-showcase/app/register/page.tsx:52,  
  the code was measuring the input element's width (which is fixed at           
  28rem/448px), when it should measure the text content width like the React    
  Native version does.                                                          
                                                                                
  The React Native version (HingeInput.js:109-115) uses onContentSizeChange to  
  measure the actual text width, not the input box width.                       
                                                                                
  The Fix                                                                       
                                                                                
  I added a hidden <span> element (page.tsx:83-89) that measures the actual text
   content width and updates the measurement whenever the value changes         
  (page.tsx:44-49).

  1. The text rotates as it did before                                          
  2. The text slides horizontally to the right over 3 seconds (matching the     
  React Native behavior)                                                        
  3. The slide distance is calculated as: containerWidth - textContentWidth -   
  padding
